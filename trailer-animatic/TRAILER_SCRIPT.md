## Re-render

Every gameplay shot is a real clip of the game (`clips/`), staged and filmed frame by frame; title cards are stills.
Change the timing (`beats`), the text, the sounds, the staging of a frame or the direction of a clip (`TRAILER.clips`) in `trailer-animatic/trailer.config.mjs`, then:

```sh
node trailer-animatic/build.mjs            # only what changed
node trailer-animatic/build.mjs --clips    # every gameplay clip again
node trailer-animatic/build.mjs --frames   # every storyboard still again
node trailer-animatic/build.mjs --only 04,12  # just these shots, then the video
```
